# HemaScope — AI-подсчёт клеток крови по снимку мазка

Прототип для лаборатории без гематологического анализатора. Лаборант фотографирует поле зрения
мазка крови (микроскоп, иммерсия ×100) — система:

1. проверяет качество снимка (резкость, освещение) и просит переснять плохой;
2. находит и считает **эритроциты, лейкоциты и тромбоциты** (детекция объектов, YOLO11n);
3. определяет **тип каждого лейкоцита** (5 типов, классификатор YOLO11n-cls) и помечает неуверенные;
4. по нескольким полям зрения собирает сводку мазка: число клеток, эритроцитов на лейкоцит,
   ориентировочную лейкоцитарную формулу.

> Исследовательский прототип, не медицинское изделие. Результат проверяет лаборант.

## Зачем

Общий анализ крови — один из самых частых лабораторных тестов. Там, где нет анализатора,
клетки и лейкоцитарную формулу считают вручную под микроскопом: это долго, а результат зависит
от опыта и усталости лаборанта. Автоматические анализаторы стоят дорого и требуют реагентов.
Микроскоп и смартфон есть почти везде — HemaScope превращает их в помощника для подсчёта.

**Тип AI-задачи:** компьютерное зрение — детекция объектов (3 класса) + классификация изображений
(5 классов), перенос обучения.

**Критерии успеха (заданы до обучения):** нейросеть должна превзойти классический CV-подход
по F1 для всех трёх типов клеток; mAP50 на test ≥ 0,90; средняя ошибка подсчёта эритроцитов
меньше 1 клетки на снимок; инференс одного снимка на CPU < 200 мс.

## Данные

| Набор | Что это | Объём | Роль |
|---|---|---|---|
| [TXL-PBC](https://github.com/lugan113/TXL-PBC_Dataset) (Gan et al., *Scientific Data* 12, 1694, 2025; MIT) | мазки периферической крови, боксы WBC / RBC / Platelets | 1 260 снимков, 18 143 клетки, 4 источника (BCCD, BCDD, PBC, Raabin-WBC) | обучение и тест детектора |
| Подмножество PBC внутри TXL-PBC | тип лейкоцита известен по имени исходного файла | 500 клеток, 5 типов по 100 | обучение и тест классификатора |

Разбиение train / val / test (882 / 252 / 126) — авторское, все 4 источника есть в каждой части.
Классификатор лейкоцитов использует то же разбиение: клетка со снимка из test детектора не попадает в train.

Главные особенности (`reports/eda/`):
- сильный дисбаланс: эритроцитов 16 302, лейкоцитов 1 298, тромбоцитов 543;
- тромбоциты мелкие (≈ 8% короткой стороны снимка) и есть лишь на 27% снимков;
- в BCDD и Raabin-WBC тромбоциты почти не размечены (0,03 и 0,06 на снимок против 0,7–1,0 в PBC/BCCD) —
  вероятны пропуски разметки, это влияет на оценку тромбоцитов.

## Методы

| Компонент | Что сделано |
|---|---|
| Классический baseline | Порог Оцу по окраске (B − G) → компоненты → лейкоциты и тромбоциты; эритроциты — круги Хафа. 80 комбинаций параметров перебраны на 200 снимках train |
| Детектор | YOLO11n (2,6 млн параметров), 416 px, 30 эпох, AdamW/SGD auto, косинусный LR, аугментации: поворот, отражения, сдвиг цвета окраски, мозаика. Сравнение: **перенос с COCO** против **обучения с нуля** |
| Пороги | Порог уверенности для каждого класса подбирается на val (максимум F1) и без изменений применяется к test |
| Классификатор лейкоцитов | Baseline: 23 морфологических признака (размер и дольчатость ядра, цвет цитоплазмы, текстура) → логистическая регрессия / случайный лес. CNN: YOLO11n-cls (ImageNet) |
| Проверка качества | Резкость = доля мелких деталей относительно контраста; яркость. Пороги — по перцентилям train |
| Оптимизация | Экспорт детектора в ONNX, проверка совпадения подсчёта и замер скорости на CPU |

## Результаты

> Цифры ниже — CPU-профиль (416 px, 30 эпох, seed 0). После `python scripts/run_all.py --profile gpu`
> все таблицы и графики в `reports/` пересчитываются автоматически; полная сводка — `reports/results/results.md`.

**Детекция и подсчёт клеток (test, 126 снимков, официальное разбиение TXL-PBC)**

| Метод | mAP50 | mAP50-95 | F1 лейкоциты | F1 эритроциты | F1 тромбоциты | Ошибка подсчёта эритроцитов, клеток/снимок | Время, мс (CPU) |
|---|---|---|---|---|---|---|---|
| Классический CV (Оцу + Хаф) | — | — | 0,909 | 0,813 | 0,321 | 3,11 | — |
| **YOLO11n, перенос с COCO** | **0,985** | **0,845** | **0,996** | **0,941** | **0,904** | **1,14** [0,91; 1,38] | 50 (36 в ONNX) |
| для сравнения: YOLO11s у авторов датасета¹ | 0,984 | 0,858 | | | | | GPU |

¹ Gan et al., 2025, то же разбиение, GPU. Статья BloodContourNet (Diagnostics 2026) получает 0,991 / 0,878 на YOLOv26-L
с доработками, но на своём разбиении 7:2:1 — напрямую не сравнимо.

Пороги уверенности подобраны на val (лейкоциты 0,35, эритроциты 0,70, тромбоциты 0,675), F1 — при IoU ≥ 0,5,
в квадратных скобках — 95% bootstrap-интервал по снимкам.

**Критерии успеха:** нейросеть лучше классического CV по всем трём классам — выполнено; mAP50 ≥ 0,90 — выполнено
(0,985); < 200 мс на снимок на CPU — выполнено (50 мс); ошибка подсчёта эритроцитов < 1 клетки — **не выполнено**
(1,14, интервал [0,91; 1,38] касается порога). Основные пропуски — слипшиеся эритроциты в плотных полях BCCD.

**Классификатор типов лейкоцитов** (500 клеток PBC, 5-кратная кросс-валидация): YOLO11n-cls — **97,4%**
(macro F1 0,974), baseline на 23 морфологических признаках — 94,4%. CNN лучше в 4 фолдах из 5, в одном — равны.

**Находки при анализе**
- **Правило краевых клеток.** 263 из 267 «лишних» эритроцитов — клетки у края кадра. Протокол разметки:
  «у края — только если видно больше половины». Постобработка по этому правилу (доля 0,45 подобрана на val)
  подняла F1 эритроцитов с 0,889 до 0,941 и уменьшила ошибку подсчёта с 2,18 до 1,14.
- **Дубли разметки.** В 5 файлах — 47 точных дублей боксов; удаляются при загрузке (YOLO делает так же).
- **Нет почти-дубликатов train↔test** (методика BloodContourNet): минимальное расстояние pHash 9 бит (порог 5),
  максимальный SSIM 0,77 (порог 0,90); сходство CNN-признаков test→train такое же, как train→train.
- **Тромбоциты в BCDD и Raabin-WBC почти не размечены** (0,03 и 0,06 на снимок против 0,7–1,0 в PBC/BCCD).
- **Строгий mAP.** Собственный COCO-подобный расчёт (сопоставление по уверенности) даёт mAP50-95 0,774
  [0,748; 0,797] — валидатор Ultralytics сопоставляет по IoU и даёт больше; для сравнения со статьями — его цифры.
- **Устойчивость.** Размытие σ = 3 снижает F1 эритроцитов на 2 пункта, проверка качества отклоняет 73% таких снимков;
  при σ = 4 — 90%. Нормальные снимки отклоняются в 0–2% случаев.
- **ONNX** ускоряет инференс в 1,6 раза (58 → 36 мс); подсчёт совпадает на 91% снимков, расхождение ≤ 2 клеток
  (ONNX работает с квадратным входом, PyTorch — с прямоугольным).

Дополнительные эксперименты (обучение с нуля, 3 seed с доверительным интервалом, модель без источника
Raabin-WBC, YOLO11s) — в `reports/results/results.md` после запуска `run_all.py`.

## Запуск

Обученные на CPU веса уже лежат в `runs/` — для демо обучение не нужно:

```bash
python -m pip install torch torchvision          # или CUDA-версия, см. ниже
python -m pip install -r requirements.txt
python app/app.py                                # демо: http://127.0.0.1:7860
python app/app.py --onnx                         # то же на ускоренной ONNX-модели
```

### Полное обучение на видеокарте

1. Python 3.10–3.13, драйвер NVIDIA. Создайте окружение: `python -m venv .venv`, затем активируйте
   (`.venv\Scripts\activate` в Windows, `source .venv/bin/activate` в Linux).
2. PyTorch с CUDA — команду под свою версию CUDA возьмите на https://pytorch.org/get-started/locally/,
   например: `pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124`.
   Проверка: `python -c "import torch; print(torch.cuda.is_available())"` должно напечатать `True`.
3. `pip install -r requirements.txt`
4. `python scripts/run_all.py --profile gpu`

Профиль `gpu`: 640 px, 100 эпох; запуски — YOLO11n с переносом (seed 0, 1, 2), YOLO11n с нуля,
YOLO11n без Raabin-WBC, YOLO11s. Датасет и предобученные веса скачиваются сами. На RTX 3060-классе — примерно
3–5 часов. Если не хватает видеопамяти — `--batch 8`. Прервать можно в любой момент: повторный запуск продолжит
с места остановки. CPU-версии моделей из архива автоматически переносятся в `runs/previous/`.

Без видеокарты: `python scripts/run_all.py --profile cpu` (416 px, 30 эпох, ~9 ч на 2 ядрах).

Проверено: Python 3.13, ultralytics 8.4.211, torch 2.15 (CPU, Intel Xeon, 2 потока). Версии библиотек — в
`requirements.txt`; seed фиксирован, `deterministic=True`.

Тесты: `python -m pytest -q tests`.

## Ответственный AI и ограничения

| Риск | Что сделано |
|---|---|
| Неверный подсчёт на плохом снимке | проверка резкости и яркости до анализа; пороги откалиброваны на train, проверены на испорченных снимках |
| Ошибка типа лейкоцита | уверенность < 60% помечается «проверить вручную»; в формулу такие клетки не входят |
| Ложное ощущение «диагноза» | выводятся подсчёт и соотношения, а не «норма/патология»; дисклеймер в интерфейсе |
| Сдвиг между лабораториями | метрики по каждому из 4 источников; отдельный эксперимент с источником, которого не было в обучении |
| Приватность | работает локально, снимки никуда не отправляются; в данных нет персональной информации |

Ограничения:
- **Нет идентификаторов пациентов и мазков** в TXL-PBC — разбиение по снимкам, а не по пациентам; почти-дубликатов
  нет, но корреляцию снимков одного мазка исключить нельзя. Результаты — «внутри датасета», не клиническая точность.
- **Концентрацию (клеток/мкл) система не определяет** — нужна калибровка микроскопа и толщины мазка.
- **Лейкоцитарная формула неполная:** в обучении 5 типов из PBC, сегментоядерных нейтрофилов (самый частый тип)
  нет. Классификатор проверен только на снимках одного источника; на других он заметно менее уверен.
- **Не входят:** бласты, атипичные клетки, мишеневидные и серповидные эритроциты, агрегаты тромбоцитов.
- Не проверено на казахстанских мазках и смартфонных снимках через окуляр. Не медицинское изделие.
